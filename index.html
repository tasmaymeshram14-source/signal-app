This build recognizes five gestures (open palm, fist, thumbs up, peace sign, pointing) and a handful of spoken commands ("hello", "what time is it", "stop listening") to show the control loop working end to end. It isn't hooked up to a real AI model yet — that's the next step, and it needs your own API key plus a small backend to keep that key private, since it can't run safely in a public webpage's code.
